# Synthetic Image Classification with a CNN — "Real vs. Fake Logo" Proof of Concept

A from-scratch synthetic dataset (generated entirely in code — no external download needed) used to build and validate a complete CNN image classification pipeline: data generation, preprocessing, model design, training, and evaluation.

## Read this before the accuracy number

The two classes are generated by two different, deterministic drawing functions — "real" logos are a fixed black circle with text, "fake" logos are randomly colored, blurred ellipses. They're structurally easy to separate by design. **The model's 100% test accuracy reflects how visually distinct these two synthetic classes are, not real-world counterfeit-logo detection performance.** A real version of this problem — genuine vs. actual counterfeit product logos — would score meaningfully lower, because real counterfeits are specifically designed to look convincing, which is what makes that a hard problem in the first place.

This project exists to demonstrate the pipeline (image generation, preprocessing, CNN architecture, training, evaluation with a confusion matrix) end-to-end on data where the ground truth is unambiguous — a clean way to verify every step works correctly.

## Project structure

```
├── synthetic_logo_classification.ipynb   # Full pipeline: generate → preprocess → CNN → evaluate
└── requirements.txt
```

No dataset file to download — the notebook generates its own 400-image dataset (200 real, 200 fake) on first run.

## Approach

1. **Dataset generation** — "real" logos: fixed black circle + text. "fake" logos: random-colored ellipse with Gaussian noise and blur.
2. **Preprocessing** — resize, normalize to [0,1], one-hot encode labels.
3. **Model** — a 3-block CNN (32→64→128 filters) with dropout, sized appropriately for a 400-image dataset.
4. **Evaluation** — confusion matrix and classification report on a held-out test split.

## Results

| Step | Result |
|---|---|
| Dataset | 400 synthetic images (200 real, 200 fake) |
| Model | 3-block CNN, ~400K parameters |
| Test accuracy | 100% (on synthetic, visually distinct classes — see note above) |
